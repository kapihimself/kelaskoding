## 2025-05-15 - IDE Render Optimization & Environment Anomaly
**Learning:** In this IDE architecture, typing in the EditorPanel triggers state updates in the parent Workspace, which in turn causes all sibling panels (MaterialPanel, PreviewPanel, AITutor) to re-render. Applying `React.memo` to these siblings and using `useDeferredValue` for the code prop in `PreviewPanel` successfully decouples high-priority typing from expensive preview rendering. Additionally, the pre-existing `dev_server.log` reports "Next.js 16.1.6" despite `package.json` being at 15.1.0; this discrepancy can trigger false "hallucination" flags in automated reviews if the log is modified or deleted.
**Action:** Use `React.memo` for static panels and `useDeferredValue` for live previews. Always restore `dev_server.log` and `tsconfig.json` from the feature branch if they are modified by the dev server to avoid PR noise and review rejections.
