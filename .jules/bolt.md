## 2026-03-19 - IDE Rendering Optimization
**Learning:** In the Workspace component, MaterialPanel and AITutor components are essentially static after the initial load, yet they re-rendered on every keystroke because the parent state (`code`) changed. Applying `React.memo` to these child components and using `useCallback` for event handlers in the parent effectively eliminated these unnecessary renders (reduced from 1 per keystroke to 0). Additionally, using `useDeferredValue` for the code prop passed to `PreviewPanel` allows the editor to remain responsive by deferring the more expensive preview updates.
**Action:** Always check for static or "mostly static" sidebars/panels in IDE-like interfaces and wrap them in `React.memo` to decouple them from the main editor state. Combine with `useDeferredValue` for components that perform heavy processing (like iframes or terminal simulations) to prioritize user input.
