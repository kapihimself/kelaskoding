## 2025-05-15 - Combined React Optimization Pattern
**Learning:** In interactive IDE applications with frequent state updates (keystrokes), static sidebar panels like MaterialPanel and AITutor can become performance bottlenecks if they re-render on every character change. Using `React.memo` for these static components, combined with `useDeferredValue` for the heavy preview update, significantly improves editor responsiveness.
**Action:** Always memoize peripheral UI components that don't depend on the core input state. Use `useDeferredValue` to deprioritize expensive preview renders, allowing the editor's high-priority updates to remain fluid. Remove manual `setTimeout` debouncing in children when using `useDeferredValue` at the parent level to avoid redundant scheduling.
