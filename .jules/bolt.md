## 2026-05-30 - Multi-pane Workspace Rendering Bottleneck
**Learning:** In a 3-pane IDE layout where a central Editor updates state frequently (every keystroke), sibling components like `MaterialPanel` and `AITutor` re-render unnecessarily because they share the same parent state in `Workspace.tsx`. This consumes CPU cycles and can lead to typing lag as the tree grows. Combining `React.memo` for static panels with `useDeferredValue` for the code-dependent `PreviewPanel` provides the best balance of responsiveness and visual feedback.
**Action:** When building multi-pane interfaces with high-frequency state updates, proactively memoize sibling panels that don't depend on the fast-changing state, and use `useDeferredValue` to decouple the main input thread from expensive side-effects like iframe reloads.
