# Product Requirement Document (PRD) - KodeLokal "One-Stop Solution"

## App Overview
A web-based learning platform (LMS) where users can learn coding interactively in Bahasa Indonesia. This platform aims to be a comprehensive solution for aspiring Software and AI Engineers.

## Key Features
1.  **Landing Page Premium:**
    - Hero section with glow effects.
    - Track selection cards (Software vs AI).
    - Highlights of unique features: AI Tutor, Interactive Quizzes, and Gamification.

2.  **The Classroom (Interactive IDE):**
    - 3-Pane Layout (Material - Editor - Preview).
    - **AI Tutor:** Contextual sidebar that provides hints and explanations using AI logic.
    - **Interactive Quizzes:** End-of-lesson knowledge checks to ensure comprehension.

3.  **Gamification (Advanced):**
    - **XP System:** Earn points for completing lessons and passing quizzes.
    - **Badges/Achievements:** Unlock badges for reaching milestones.
    - **Progress Bar:** Track overall track completion.
    - **Celebration:** Confetti on lesson/quiz success.

4.  **Smart Validation System:**
    - DOM checking for Web tracks.
    - Regex logic for AI tracks.
    - Quiz validation for multiple-choice answers.

## User Flow
1. User lands on Home, sees their stats (XP/Badges).
2. Picks a Track.
3. Enters Classroom -> Reads material -> Interacts with AI Tutor if stuck -> Types code -> Pass Validation -> Take Quiz -> Earn XP -> Next Lesson.
