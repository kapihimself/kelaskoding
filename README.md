## 🌟 Vision & Mission
**KodeLokal** aims to bridge the tech talent gap in Indonesia by providing an accessible, engaging, and deeply localized interactive coding platform. We are building the "FreeCodeCamp/Codecademy of Indonesia" with a premium, Gen Z & Millennial-focused aesthetic and a supportive learning environment.

---

## 📈 Market Opportunity: Why Indonesia?
- **Massive Youth Demographic:** Indonesia has one of the largest young populations globally, with Gen Z and Millennials highly eager to switch careers into tech.
- **Language Barrier:** Most top-tier coding platforms are strictly in English. KodeLokal speaks to users in their native language—casual, approachable, and supportive *Bahasa Indonesia*.
- **Growing Tech Ecosystem:** The demand for Software and AI Engineers in Southeast Asia is skyrocketing. KodeLokal prepares the local workforce to meet this global demand.

## ✨ Key Features

### 1. 🎓 The Classroom: 3-Pane Interactive IDE
A seamless learning experience without the need to install anything locally.
- **Materi & Instruksi:** Friendly, bite-sized lessons in *Bahasa Indonesia*.
- **Code Editor:** Professional-grade text editor right in the browser.
- **Live Canvas/Preview:** Real-time feedback and results of the user's code.

### 2. 🧠 Dual Career Tracks
Tailored learning paths for the two most in-demand tech roles:
- **Jalur Software Engineer:** Focuses on Web Development (HTML, CSS, JS). Features real-time browser preview powered by `@codesandbox/sandpack-react`.
- **Jalur AI Engineer:** Focuses on Python syntax & Prompt Engineering. Uses an intelligent "Output Simulation" via Monaco Editor to emulate terminal execution.

### 3. 🤖 Smart Validation System
Unlike basic string matching, KodeLokal deeply understands the user's input:
- **DOM Checking (Web):** Validates if HTML elements are accurately formed and styled in the Document Object Model.
- **Syntax Logic (AI/Python):** Uses Regex and structural checks to ensure Python commands are logically sound.

### 4. 🎮 Gamification & Encouragement
Designed to keep motivation high with progress bars, confetti celebrations, and a helpful "Lihat Kunci Jawaban" (See Solution) fallback. All error messages are framed as supportive encouragement (e.g., "Coba lagi yuk!").

## 🛠️ Tech Stack & Architecture

We leverage a cutting-edge, modern web stack to deliver a fast, premium experience:

- **Framework:** **Next.js 14** (App Router) for unparalleled performance and SEO.
- **Styling:** **Tailwind CSS**, **Lucide Icons**, and **Framer Motion** for fluid animations.
- **UI Components:** **Shadcn UI** (Radix Primitives) providing robust, accessible foundations.
- **State Management:** **Zustand** for lightweight, scalable progress tracking.
- **Editor Engines:**
  - `@codesandbox/sandpack-react` for real-time web previews.
  - `@monaco-editor/react` for terminal simulation and Python execution.
- **Design Aesthetic:** Premium Dark Mode (`zinc-950`/`slate-900` backgrounds, glassmorphism, subtle glows) inspired by Vercel and UI8.
